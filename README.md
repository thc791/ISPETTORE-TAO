# Ispettore TAO - Bittensor Subnet & ETF Terminal

Terminale Python per il monitoraggio dell'ecosistema Bittensor:
- Prezzo TAO spot e ETF/ETP (STAO, ATAO, VIRTAO, VTAO, GTAO)
- Top 10 Subnet Proven e Top 10 Subnet Promettenti
- Calcolo liquidità reale di uscita (Mark-to-Exit / Slippage AMM)
- Analisi Web Live e Copilot Prompt tramite Google Gemini
